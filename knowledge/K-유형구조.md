# K-유형구조 (A3 카피라이터 · A6 재작성)

모든 유형 공통: 1번 = 훅(이미 선택된 훅을 그대로 사용), 마지막 = 요약 + CTA 하나. 장수는 사용자 선택값을 따르되, 기본 장수에서 늘면 핵심 카드를 늘리고 줄면 핵심 카드를 줄인다. `imageSlot`은 아래 표대로.

## 리스트형 `list` — 기본 6장, 기본 목적: 저장
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | 선택된 훅 | hero |
| 2 | 공감 | 독자의 현재 상황·불편 한 장면 | none |
| 3~5 | 핵심 ①②③ | 번호 + 키워드 헤드라인, 본문은 이유 한 줄 + 방법 한 줄 | none |
| 6 | 요약+CTA | 세 핵심을 한 줄로 묶고 CTA | none |
브릿지 예: `다음은 가장 많이 틀리는 것` / `세 번째가 핵심`

## 제품판매형 `sales` — 기본 7장, 기본 목적: 링크 클릭
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | 고민 공감 훅, **제품명 없음** | none 또는 hero(분위기 사진) |
| 2 | 제품 등장 | "그래서 찾은 게" + 제품명, 한 줄 포지셔닝 | side |
| 3 | 특징 ① | 독자 문제 → 이 기능이 해결, 체감 표현 | side |
| 4 | 특징 ② | 같은 구조, 다른 문제 | side |
| 5 | 후기/비교 | 구매자 호평 2개 또는 일반 제품과의 차이 | none |
| 6 | 가격·구성 | "약 ○만 원대", 구성품, 어디서 | side |
| 7 | CTA | 프로필 링크/댓글 "링크" 요청 하나 | none |
주의: 아쉬운 점 1개를 5번 또는 6번에 솔직히 넣으면 신뢰가 올라간다("무게는 조금 있어요").

## 문제해결형 `problem` — 기본 6장, 기본 목적: 댓글
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | 실수·오해를 제기하는 훅 | hero(선택) |
| 2 | 실수 ① | 헤드라인 `❌ ○○하기` / 본문 `→ 대신 ○○` + 이유 | none |
| 3 | 실수 ② | 같은 구조 | none |
| 4 | 실수 ③ | 같은 구조 | none |
| 5 | 정리 | 세 실수를 한 문장으로 | none |
| 6 | CTA | "몇 번에 해당하세요? 댓글로" 같은 참여 CTA | none |

## 체크리스트형 `checklist` — 기본 7장, 기본 목적: 저장
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | "○○ 전 체크 6가지" 류 | hero(선택) |
| 2 | 왜 필요한가 | 이걸 안 보면 생기는 손해 한 장면 | none |
| 3 | 항목 ①② | `☐ 동사로 끝나는 항목` 2개 + 각 한 줄 이유 | none |
| 4 | 항목 ③④ | 같은 구조 | none |
| 5 | 항목 ⑤⑥ | 같은 구조 | none |
| 6 | 전체 요약표 | 6개 항목을 한 장에 목록으로(본문 6줄 허용, 한 줄 12자 이내) | none |
| 7 | CTA | "저장해 두고 살 때 꺼내 보기" | none |

## 비교형 `compare` — 기본 6장, 기본 목적: 링크 클릭
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | "A vs B, 뭐가 다를까" 또는 비포 상황 | none |
| 2 | 비포 / A | 비포 상태 또는 일반 제품의 한계 | side |
| 3 | 애프터 / B | 이 제품으로 바뀐 상태 | side |
| 4 | 차이 포인트 ① | 기준 하나(가격·크기·사용감…)로 비교 | none |
| 5 | 차이 포인트 ② | 다른 기준 | none |
| 6 | CTA | "어느 쪽이 맞는지 알려드릴게요 → 링크/댓글" | none |

## 스토리형 `story` — 기본 7장, 기본 목적: 팔로우
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | 결과나 반전을 먼저("이걸로 아침 20분 벌었다") | hero(선택) |
| 2 | 상황 | 1인칭 현재 상황, 구체적 장면 | none |
| 3 | 갈등 | 뭐가 문제였고 뭘 시도했는지 | none |
| 4 | 전환 | 제품/방법을 만난 계기 | side |
| 5 | 결과 | 바뀐 뒤 장면, 수치는 출처 있을 때만 | side |
| 6 | 교훈 | 한 문장 통찰 | none |
| 7 | CTA | "다음 편은 ○○" + 팔로우 | none |
카드 끝 브릿지 필수(10자 이내). 말투는 설정값이되 1인칭.

## 후기 모음형 `reviews` — 기본 6장, 기본 목적: 링크 클릭
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | "후기 ○○개에서 공통으로 나온 말" | hero(선택) |
| 2~4 | 후기 ①②③ | 인용 형식(layout quote). 실명·사진·원문 복제 금지, **요지를 재서술** + 출처 줄 "구매자 후기 중" | none |
| 5 | 공통점 | 세 후기의 공통 결론 한 줄 + 아쉬운 점 하나 | side |
| 6 | CTA | 링크 | none |

## Q&A형 `qna` — 기본 6장, 기본 목적: 댓글·DM
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | "제일 많이 받은 질문 4개" | none |
| 2~5 | Q&A ①~④ | 헤드라인 `Q. …`(16자) / 본문 `A. …` 2~3줄. 질문은 실제 검색어·후기 기반 | none(2번만 side 허용) |
| 6 | CTA | "또 궁금한 건 댓글로" | none |

## 랭킹형 `ranking` — 기본 7장, 기본 목적: 저장
| # | role | 쓰는 것 | imageSlot |
|---|---|---|---|
| 1 | 훅 | "○○ TOP 5, 기준은 하나" | none |
| 2~6 | 5위→1위 | 역순(긴장감). 헤드라인 `5위 ○○`, 본문 왜 이 순위인지 한 기준으로 | side(1위만) |
| 7 | CTA | "저장해 두고 고를 때" | none |
기준은 하나(가격·휴대성·초보 적합 등)로 고정하고 1번 카드에 밝힌다.

## CTA 문장 은행 (목적별)
- 저장: `저장해 두고 비교하세요` / `살 때 꺼내 보세요` / `나중에 찾기 힘드니 저장`
- 링크 클릭: `프로필 링크에서 확인` / `댓글에 "링크" 남기면 보내드려요`
- 댓글: `몇 번에 해당하세요?` / `당신의 방법은요?`
- 팔로우: `다음 편은 ○○ 편` / `매주 이런 정리 올라와요`
- DM·문의: `고민 있으면 DM 주세요` / `내 상황엔 뭐가 맞는지 물어보세요`

## 재작성 규칙 (A6)
- 같은 role, 같은 메시지 범위 안에서 **표현만** 바꾼다. 앞뒤 카드와 흐름이 끊기면 안 된다.
- 기존 헤드라인과 첫 3글자가 같으면 안 된다(눈에 띄게 다르게).
