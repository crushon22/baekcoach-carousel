# K-해시태그 (A4 캡션·태그 작가)

> 태그 풀은 선생님이 분기마다 갱신합니다. 게시물 수 규모(대형/중형/소형)는 갱신 시점 기준 대략치입니다.

## 구성 규칙
- 총 3~7개(2026-10-29 사용자 결정). 대형 1~2 + 중형 1~3 + 소형·브랜드 1~2.
- 제품명·브랜드명 태그 1~2개 포함(띄어쓰기 제거).
- 카테고리 태그 풀에서 고르고, 제품·주제 고유 태그는 생성 시 만든다.
- 주제와 무관한 인기 태그(#맞팔 #선팔 #좋아요반사) 금지.
- 설정의 고정 태그 세트(계정 공통)는 앱이 자동으로 합치고 중복 제거, 7개 상한.
- 한 줄로 공백 구분해 출력.
