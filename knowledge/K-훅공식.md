# K-훅공식 (A2 훅 작가)

훅은 피드에서 손가락을 멈추게 하는 1번 카드 문장이다. 16자 이내(2줄이면 줄당 6~12자), 0.5초 안에 읽혀야 한다. 3안을 낼 때는 **파격형 · 질문형 · 반전형** 각 1개.
> 2026-10-30 갱신: 2024~2026 쿠팡 파트너스·공구 계정에서 실제로 반응이 좋았던 첫 문장을 모아 공식으로 정리(사용자 지시 "트렌드 분석하고 댓글 많이 달린 게시물을 보고").

## 훅의 목적
- 훅은 **이 제품의 가장 파격적인 한 가지**(색·모양·효과·가격·상황)로 "어? 저게 뭐지?" 또는 "나도 저거 갖고 싶다"를 만든다. 제품을 설명하지 않는다.
- 절대 쓰지 않는 것: 캐러셀 자체를 말하는 메타 문장 — `3장만 보면`, `N장 정리`, `끝까지 보세요`, `이 글 보면 감이 와요`. 게시물을 팔려는 말이라 아무도 멈추지 않는다.
- 장점 나열(`가볍고 편한 운동화`)·반듯한 광고 카피(`건강한 습관을 위한 프리미엄 ○○`)도 훅이 아니다. 생활 장면의 말로 바꾼다.
- 말투: 실제로 반응이 좋은 게시물은 거의 다 구어체다 — `~잖아요`, `~라고?`, `못 참지`, `어쩔 뻔`, `~임`. 설정 말투(존댓말/반말)는 지키되 문장 끝은 놀람·의문·감탄 하나(물음표나 느낌표 1개). 이모지는 쓰지 않는다(캔버스 글씨).
- 브랜드·캐릭터·색처럼 눈에 띄는 고유 요소가 사진에 보이면 꼭 넣는다 — `헬로키티 거울이 / 빛까지 켜진다고?`가 `동그란데 / 빛까지 켜져요`보다 세다.

## 공식 (반응이 좋은 순서가 아니라 상황에 맞게 고른다)
### 1. 문의 폭주형 — 사회적 증거 + "나만 몰랐나"
공식: `다들 [이거] 어디서 샀냐고 물어봐서` / `어디 거냐고 [N]번 들은 [제품]`
- `다들 어디서 샀냐고 / 묻는 그 가방`
- `이 색 뭐냐고 / 하루 세 번 들었어`
- `가방에 달았더니 / 다들 묻는 키링`
팁: 댓글 유도와 바로 이어진다(궁금하면 댓글로). 수치("DM 100개")는 근거 없으면 쓰지 않고 "다들", "자꾸"처럼 분위기 표현으로만.

### 2. 이거 하나로 끝 — 상황/고민 → 해결 한 줄
공식: `[상황/고민]이라면 이거 하나면 [결과]` / `[장소]에 이거 하나 [했더니] [결과]`
- `현관에 이거 하나 / 붙였더니 정리 끝`
- `텀블러 세척 지옥 / 버튼 하나로 끝`
- `가벼운데 많이 / 들어가는 가방 찾으면`
팁: 생활용품·주방·육아에 가장 강하다. 결과는 사진에 보이는 범위 안에서.

### 3. 나만 알고 싶은 — 비밀 공유
공식: `나만 알고 싶은 [제품]` / `친구한테 링크 [N]개 뿌린 [제품]` / `자취 5년 차가 진작 살 걸 한 것`
- `나만 알고 싶은 / 보부상 가방`
- `쿨톤 10년 차가 / 정착한 색`
- `자취 5년 차가 / 진작 살 걸 한 것`
팁: 친구가 귓속말하는 톤이라 광고 티가 적다. "N년 차"는 사용자 입력에 있을 때만, 없으면 "오래 써 본 사람이".

### 4. 가격 충격형 — 숫자 하나
공식: `[가격] 보고 [반응]` / `만 원도 안 하는 [제품]` / `[가격]대인데 [비싼 느낌]`
- `이거 가격 보고 / 소리 질렀잖아요`
- `3만 원대인데 / 명품 룩 신발`
- `만 원도 안 하는 / 백화점 발색`
팁: 가격은 입력(가격 칸·facts)에 있을 때만 숫자로. 없으면 "가격 보고 놀란"처럼 숫자 없이.

### 5. 정체 질문형 — 사진과 문장을 어긋나게
공식: `이게 [A]야 [B]야?` / `[의외의 대상]이 이걸?` / `[제품]이 [이 색/이 모양]이라고?`
- `이게 피규어야 / 향수야?`
- `신발이 / 이 색이라고?`
- `헬로키티 거울이 / 빛까지 켜진다고?`
- `쿠팡에 이런 게 / 있다고?`
팁: 사진에서 실제로 보이는 반전이어야 한다. 가장 "파격형"에 가까운 공식.

### 6. 소속 공감형 — 타깃 호명
공식: `[타깃]이라면 필수템` / `파우치에 이거 없으면 [타깃] 아님` / `[타깃] 안 보면 후회`
- `파우치에 이거 없으면 / 여쿨 아님`
- `출근길 1만 보 / 발 안 아픈 신발`
- `자취생이면 / 이건 그냥 사세요`
팁: 타깃은 카테고리 파일의 독자상에서. 비하·배제 표현은 쓰지 않는다.

### 7. 시즌·상황 회상형
공식: `[시즌]에 이거 없었으면 어쩔 뻔` / `퇴근하고 10분, [결과]`
- `올여름 이거 없었으면 / 어쩔 뻔`
- `퇴근하고 10분 / 집이 달라지는 템`
팁: 사용 장면이 떠올라 저장된다. 시즌은 카테고리 파일의 시즌 키워드와 맞춘다.

### 8. 품절·선점 긴박형 (굿즈·한정판·뷰티 인기템에만)
공식: `남들 다 사기 전에` / `품절되면 또 기다려야` / `또 품절이라고?!`
- `품절 풀렸대 / 지금 아니면 또 대기`
- `다이소 갔는데 / 또 품절이라고?!`
팁: "품절"·"대란"은 사실 주장이다 — facts·입력에 근거가 있을 때만. 없으면 쓰지 않는다.

### 9. 못 참지 직진형 (굿즈·캐릭터)
공식: `실물 보자마자 이건 못 참지` / `셋 중 어떤 [캐릭터] 데려올래?`
- `실물 보자마자 / 이건 못 참지`
- `셋 중에 어떤 / 피카츄 데려올래?`
팁: 설명보다 감탄 + 선택 질문이 댓글을 만든다.

### 10. 반전형 — 상식과 반대
공식: `[흔한 믿음]할수록 [반대 결과]` / `비싼 게 답은 아니에요`
- `비싼 에어랩이 / 손해인 이유`
- `청소기 안 사도 / 되는 줄 알았어`
- `세탁을 자주 하면 / 안 됩니다`
팁: 반전은 2번 카드에서 근거를 대야 한다. 근거 없는 반전은 어그로로 읽힌다.

### 11. 숫자형 — 구체 숫자 + 결과/대상 (facts 에 숫자가 있을 때만)
공식: `[숫자][단위] [대상/결과]`
- `60만 원 쓰기 전에`
- `설거지 10분 줄이는 법`
팁: 반올림한 큰 숫자보다 "47개"처럼 구체 숫자. 숫자는 facts·입력에 있는 것만.

### 12. 결과형 — 바꾼 뒤 얻은 결과
공식: `[행동] 바꾸고 [결과]` / `[제품] 하나 바꿨는데 [결과]`
- `틴트 하나 바꿨는데 / 얼굴이 달라짐`
- `신발 하나 바꿨는데 / 키 커 보임`
팁: 결과에 수치를 쓰려면 출처가 있어야 한다. 없으면 "눈에 띄게", "확" 같은 체감 표현.

## 3안 고르는 법
- 파격형 자리: 공식 5·1·4·9 중 사진에 가장 맞는 것(브랜드·캐릭터·색·가격이 보이면 그것).
- 질문형 자리: 공식 5(질문)·6·9의 선택 질문·1("어디서 샀냐고?").
- 반전형 자리: 공식 10·12·3.
- hookPick: 사진에 보이는 고유 요소를 담은 파격형이 제대로 나왔으면 파격형.

## 금지 제목 패턴
- `3장만 보면`, `N장 정리`, `끝까지 보세요`, `이 글 보면 감이 와요` (캐러셀 메타 문장)
- `~하는 방법`, `~소개`, `~에 대하여`, `~총정리`, `~꿀팁 모음` (설명형)
- `오늘은 ~를 가져왔어요`, `안녕하세요` (빈말)
- `충격`, `경악`, `대박`, `미쳤다`, `이거 모르면 큰일` (낚시어·공포형 — 식상해서 반응이 죽는다)
- `1위`, `최저가`, `100%`, `세계 최초`, 연예인 이름 끌어오기 (근거 없는 단정·초상 위험)
- 브랜드명만 있는 제목 (`다이슨 에어랩`)

## 카테고리별 강한 축
뷰티 → 발색·전후·"이 색 뭐냐고" / 패션 → 가격 충격·"어디 거냐고"·코디 / 식품 → 시간·보관·"어디서 샀냐고" / 리빙 → 이거 하나로 끝·시즌 회상 / 가전 → 돈·스펙의 체감·반전 / 육아 → 안전·"전쟁이라면" / 건강 → 습관·실수 / 반려 → 반려인의 실수·안전 / 굿즈 → 못 참지·품절·정체 질문

## 사고 싶게 만드는 흐름 (커버 → 안쪽 → 마지막)
- 커버: 위 공식 하나로 멈추게 한다.
- 안쪽: 그 파격을 **눈으로 확인**시키는 디테일(발색·소재·각도)과, 쓰면 달라지는 장면("이거 신고 나가면 다들 한 번씩 봐요")을 번갈아. 장점 나열이 아니라 "갖고 싶다"가 쌓이게.
- 마지막(CTA): 갖고 싶어진 사람이 바로 움직이게 — 댓글 단어 + 얻는 것(링크를 DM으로). K-댓글유도.

## 훅과 본문의 관계
훅 카드 본문은 1~2줄로 훅을 보강만 한다. 답을 다 주지 않는다. 예: 훅 `60만 원 쓰기 전에` / 본문 `후회하는 사람들의\n공통점 하나`.
