# K-훅공식 (A2 훅 작가)

훅은 피드에서 손가락을 멈추게 하는 1번 카드 헤드라인이다. 16자 이내, 최대 2줄. 반드시 아래 네 공식 중 하나로 쓴다. 3안을 낼 때는 **숫자형 · 질문형 · 반전형** 각 1개.

## 1. 숫자형 — 구체 숫자 + 결과/대상
공식: `[숫자][단위] [대상/결과]`
- `60만 원 쓰기 전에`
- `후기 300개 읽고 고른 것`
- `퇴근 후 30분, 이렇게`
- `설거지 10분 줄이는 법`
- `이유식 실수 3가지`
팁: 금액·개수·시간이 독자 머릿속 숫자와 다를수록 강하다. 반올림한 큰 숫자보다 "47개"처럼 구체 숫자가 더 멈추게 한다.

## 2. 질문형 — 독자가 속으로 "나도"라고 답하는 질문
공식: `왜 [내 상황]은 [안 되는 결과]일까?` / `[행동] 하고 계세요?`
- `왜 내 컬은 금방 풀릴까?`
- `물티슈로 발 닦고 계세요?`
- `이거 아직 사세요?`
- `비싼 게 정말 좋을까?`
- `저장만 하고 안 보시죠?`
팁: 질문에 독자의 실수나 습관을 넣으면 공감이 두 배. 답이 "아니오"로 끝나는 질문은 피한다.

## 3. 반전형 — 상식과 반대되는 주장
공식: `[흔한 믿음]할수록 [반대 결과]` / `[비쌀수록/열심히 할수록] ~한 이유`
- `열심히 올릴수록 줄어든다`
- `비싼 에어랩이 손해인 이유`
- `세탁을 자주 하면 안 됩니다`
- `좋은 사료가 독이 될 때`
- `운동 많이 하면 살 안 빠짐`
팁: 반전은 본문(또는 2번 카드)에서 반드시 근거를 대야 한다. 근거 없는 반전은 어그로로 읽힌다.

## 4. 결과형 — 바꾼 뒤 얻은 구체 결과
공식: `[행동] 바꾸고 [결과]`
- `순서만 바꾸고 흡수 2배`
- `이거 하나로 냉장고 정리 끝`
- `3일 만에 털 날림 절반`
팁: 결과에 수치를 쓰려면 출처가 있어야 한다. 없으면 "절반쯤", "눈에 띄게"로.

## 금지 제목 패턴
- `~하는 방법`, `~소개`, `~에 대하여`, `~총정리`, `~꿀팁 모음` (설명형)
- `오늘은 ~를 가져왔어요`, `안녕하세요` (빈말)
- `충격`, `경악`, `대박`, `미쳤다` (낚시어)
- 브랜드명만 있는 제목 (`다이슨 에어랩`)

## 카테고리별 강한 축
뷰티 → 전후·순서 / 패션 → 가격·코디 수 / 식품 → 시간·보관 / 리빙 → 시간 절약·정리 결과 / 가전 → 돈·스펙의 체감 / 육아 → 안전·월령 / 건강 → 습관·실수 / 반려 → 반려인의 실수·안전

## 훅과 본문의 관계
훅 카드 본문은 1~2줄로 훅을 보강만 한다. 답을 다 주지 않는다. 예: 훅 `60만 원 쓰기 전에` / 본문 `후회하는 사람들의\n공통점 하나`.
