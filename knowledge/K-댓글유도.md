# K-댓글유도 (제품 정보는 숨기고, 댓글로 물어보게 하기)

> 2026-10-29 사용자 결정. 이 도구의 주된 쓰임새다. 2026-10-30 갱신: 실제 쿠팡 파트너스 계정(스레드·틱톡·인스타) 캡션과 메타·공정위 규칙을 조사해 CTA 공식을 다시 정리.
> 카드에서는 제품이 "무엇인지"(브랜드·종류·보이는 특징)만 보여 주고, "정확히 어느 제품인지"(번호·색상명·모델명)는 숨긴다
> → 보는 사람이 궁금해서 댓글로 물어본다 → 댓글 단 사람에게 DM(머닝·인포크링크 등 자동 DM)으로 쿠팡 파트너스 링크를 보낸다.
> 게시물 본문에는 링크가 없다(캡션 링크는 어차피 클릭이 안 된다). 그래서 "링크는 프로필에"·"구매는 링크에서"는 쓰지 않는다.

## 숨기는 것 / 보여 주는 것
- 숨긴다(hide): 제품 번호·코드(987번, No.21, A2651), 색상명·호수(루비 우, 21호), 라인·시리즈명(파우더 키스), 정확한 모델명.
  입력 이름에 적혀 있어도 카드·캡션·해시태그 어디에도 쓰지 않는다. 같은 뜻의 다른 표기(987 / 987번 / #987 / 구백팔십칠)도 쓰지 않는다.
- 보여 준다(keep): 브랜드(맥, 다이슨), 상품 종류(립스틱, 청소기), 사진에 보이는 특징(쨍한 레드, 무광, 한 손에 잡히는 크기), 쓰는 상황.
- 숨긴 정보로 제품을 아는 경우(그 번호가 어떤 색·질감인지 안다면) 그 지식은 발색·질감·어울리는 상황을 묘사하는 데 쓴다. 이름·번호는 끝까지 말하지 않는다. 모르면 사진에 보이는 것만 쓴다.
- 브랜드는 숨기지 않는다. "맥 제품인 건 알겠는데 몇 번이지?"가 되어야 댓글이 달린다.

## 댓글 단어 (plan.commentWord)
- 실제로 반응이 좋은 계정들은 거의 다 **한글 2글자 명사**를 쓴다(가장 흔한 것: 상품 단어 "소파"·"선풍기"·"미니", 그다음 "링크", "나도"). 자동 DM 도구가 글자를 그대로 잡기 때문에 짧고 치기 쉬운 단어여야 한다. 숫자·이모지·영문은 쓰지 않는다.
- 단어 하나를 2글자 이내로 정한다. 우선순위: ① 상품을 바로 떠올리는 말(종류·캐릭터·색: `거울` `키티` `신발` `레드` `립`) ② 상품이 뭉뚱그려지면 `링크` ③ 그래도 없으면 `나도`.
  - 매트 레드 립스틱 → `레드` · `립` · `매트` / 헬로키티 거울 → `거울` · `키티` / 핑크 나이키 → `핑크` · `신발` / 텀블러 → `텀블` / 선풍기 → `바람` / 키링 → `키링`
- 일반 댓글에 흔히 나오는 말(`좋아요`, `예뻐요`, `ㅋㅋ`)은 피한다 — 엉뚱한 댓글에도 DM이 나간다. 게시물마다 다른 단어가 좋다(같은 단어를 계속 쓰면 자동화가 겹친다).
- 단어 하나만 쓴다. 두 개를 고르게 하지 않는다("레드 또는 매트" ✗).

## CTA 공식 (마지막 카드 · 캡션)
행동 하나 + 얻는 것. "댓글 남겨 주세요"만 덩그러니 쓰지 않는다. 링크를 **DM으로** 보내 준다는 걸 분명히 말한다.
1. 기본형: `"거울" 댓글 남기면 / DM으로 링크 보내드려요` · `댓글에 "레드" / 링크 바로 보내드려요`
2. 문의 폭주형(사회적 증거): `다들 어디 거냐고 물어봐서 / "거울" 댓글에 보내드려요` · `어디서 샀냐고 많이 물어서 / 댓글에 "링크"` — 수치("DM 100개")는 근거 없으면 쓰지 않고 "다들"·"많이"로.
3. 번호 궁금증형(숨긴 번호·색상명이 있을 때만): `이 색 번호 궁금하면 / 댓글에 "레드"` · `번호는 댓글로 / 바로 보내드려요`
4. 선택 질문 덧붙이기(여러 색·옵션이 보일 때): `몇 번이 제일 예뻐요? / 번호는 DM으로` · `둘 중 뭐가 더 끌려요?` — 열린 질문은 인스타가 권장하는 댓글 유도라 단어 요구와 같이 쓰면 "댓글 유도 낚시"로 안 읽힌다.
5. 경험 요청형(후기 느낌 게시물): `써 본 분 있어요? / 궁금하면 댓글에 "링크"`
- 숨길 번호·색상명이 없는 상품(hide 비어 있음)이면 "이 색 번호"·"번호는 댓글로"는 쓰지 않는다 — 궁금한 건 "어디서 사는지"다: `"키티" 댓글 남기면 / 링크 보내드려요` · `어디 건지 궁금하면 / 댓글에 "거울"`.
- 마지막 카드는 3줄 이내. 강조(노란색)는 댓글 단어와 "댓글"·"DM"에 준다.
- "링크는 프로필에"·"저장해 두세요"·"팔로우 하세요"로 끝내지 않는다(행동 하나).

## 카드 쓰는 법
- 커버: 브랜드·종류 + 궁금증(K-훅공식 — 문의 폭주형·정체 질문형이 댓글과 가장 잘 이어진다). 번호 자리에 "이 색", "이 번호", "딱 하나"를 쓴다.
  - 좋은 예: `맥 립스틱 중 / 딱 이 색 하나` · `이 색 뭐냐고 / 하루 세 번 들었어` · `헬로키티 거울이 / 빛까지 켜진다고?`
  - 나쁜 예: `맥 립스틱 987번 / 단 하나로`(번호 공개) · `루비 우 발색`(색상명 공개) · `3장만 보면 감이 와요`(메타 문장)
- 안쪽: 사진에 보이는 발색·질감·장면을 짚고 체감을 붙인다. 번호 대신 "이 색"으로 받는다. 한 장 한 포인트. "갖고 싶다"가 쌓이게(디테일 ↔ 쓰는 장면).
- 마지막: 위 CTA 공식 중 하나.

## 캡션
- 첫 줄(더보기 전): 커버 훅을 다른 표현으로, 궁금증을 남긴다("이 색 번호 물어보는 분이 많아서…").
- 본문 2~4줄: 사진에 보이는 포인트. 자랑·단정 없이.
- CTA 한 줄: `"거울" 댓글 남겨 주시면 DM으로 링크 보내드릴게요`. 댓글 단어는 카드와 **반드시 같은 단어**.
- 선택(자동 DM을 쓰는 계정이면 권장): `팔로우한 상태에서 댓글 남겨 주셔야 DM이 바로 가요` 한 줄 — 팔로우가 아니면 DM이 '요청함'으로 들어가 못 받는 경우가 많다(메타 규칙). 넣으면 팔로우도 같이 는다.
- "프로필 링크"는 쓰지 않는다. 해시태그에도 번호·색상명을 넣지 않는다(#맥립스틱 ○ · #맥987 ✗).

## 지키는 선(정책)
- 광고 표기: 카드의 [광고]는 필수(설정으로 끌 수 없다). 캡션 고지문은 설정에 따른다.
- "최저가"·"1위"·"품절 대란"처럼 사실 주장은 근거 없으면 쓰지 않는다(쿠팡 파트너스·공정위).
- 같은 CTA 문구를 모든 게시물에 똑같이 쓰지 않는다 — 공식을 돌려 가며 쓴다(반복 문구는 스팸 신호).

## 검수
- 숨기기로 한 글자가 카드·캡션·해시태그에 나오면 ⚠️(identity_leak). 완화 = 그 글자만 빼기(해시태그는 직접 지운다).
- 캡션 CTA의 댓글 단어가 카드와 다르면 코드가 카드 단어로 맞춘다.
